# 📊 Device Information Dashboard

A web-based dashboard built using ESP32-WROOM-32 and MicroPython that displays live system information.

## ✨ Features

- 📶 WiFi Status
- 🌐 IP Address
- ⚙ CPU Frequency
- 💾 Free RAM
- 🔑 MAC Address
- ⏱ Uptime
- 📡 WiFi Signal Strength (RSSI)

## Hardware Required

- ESP32-WROOM-32

## Software

- MicroPython
- Thonny IDE

## How to Run

1. Flash MicroPython on ESP32.
2. Upload all project files.
3. Create `secrets.py` with your WiFi credentials.
4. Run `main.py`.
5. Open the IP address shown in the Thonny console.
