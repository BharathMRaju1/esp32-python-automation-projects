# ESP32 Smart Weather Dashboard

A real-time weather dashboard built using **ESP32 (WROOM-32)** and **MicroPython**.

The ESP32 connects to Wi-Fi, fetches live weather data from the OpenWeather API, and hosts a responsive web dashboard that can be accessed from any device on the same network.

---

## Features

- Live weather updates
- ESP32 Web Server
- OpenWeather API integration
- Auto refresh every 60 seconds
- Temperature
- Feels Like
- Humidity
- Wind Speed
- Pressure
- Visibility
- Sunrise & Sunset
- Smart weather recommendation

---

## Hardware

- ESP32-WROOM-32
- Wi-Fi Network

---

## Software

- MicroPython
- Thonny IDE
